# الموجة الذكية — Smart Wave

موقع مزوّد الإنترنت «الموجة الذكية» في طرابلس.

## المحتوى
- `index.html` — الموقع كاملًا (صفحة واحدة، عربي وإنجليزي، وضع نهاري وليلي).
- `logo.svg` — شعار الشركة.

## التشغيل
افتح `index.html` في المتصفح، أو ارفعه على أي استضافة ملفات ثابتة (مثل GitHub Pages).
المكتبات (Three.js وGSAP) والخطوط تُحمَّل من الإنترنت، فيحتاج الموقع اتصالًا ليعمل كاملًا.

## قبل النشر
- رقم واتساب الشركة: المتغير `WA_NUMBER` داخل `index.html`.
- قائمة المناطق وحالة التغطية: المصفوفة `AREAS` (البيانات الحالية مثال).
- بيانات التواصل في التذييل: `[رقم خدمة العملاء]`، `[البريد الإلكتروني]`، `[رابط فيسبوك]`.
